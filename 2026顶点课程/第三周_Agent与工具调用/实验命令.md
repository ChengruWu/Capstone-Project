# 第三周两种模型的完整实验命令

本文件从原始命令清单整理；命令中的绝对 Python 路径是当时本机实际执行路径。执行工作目录均为第三周目录。原始输出仍在原来的 results/、results_7b/ 和日志目录，不改名、不改写。

## 避免覆盖的批量复现

先按 README 准备环境和模型。使用新的结果/日志目录：

```powershell
& '../第一周_LLM推理/.venv/Scripts/python.exe' -X utf8 run_experiments.py --model '../第一周_LLM推理/models/Qwen2.5-1.5B-Instruct' --quantization none --max-new-tokens 256 --results-dir results_1.5b_rerun --logs-dir logs_1.5b_rerun
& '../第一周_LLM推理/.venv/Scripts/python.exe' -X utf8 run_experiments.py --model '../第一周_LLM推理/models/Qwen2.5-7B-Instruct' --quantization nf4 --max-new-tokens 512 --results-dir results_7b_rerun --logs-dir logs_7b_rerun
```

每条批量命令运行 10 组；额外的 7B 推荐配置单次命令见文末。批量脚本拒绝覆盖，若 rerun 目录已经有结果，请换新目录名。以下是历史原始命令，直接重复运行单次命令会覆盖同名 JSON，复现时务必修改 --output。
